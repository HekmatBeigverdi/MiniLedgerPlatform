
# MiniLedger Platform

MiniLedger Platform is a monorepo-based accounting application project built with a web-first and desktop-ready architecture.

## Goals

- Build a modern accounting UI with Next.js
- Keep the project educational and phase-driven
- Prepare the codebase for a future Tauri desktop edition
- Share reusable UI, schemas, and core domain logic across apps

## Planned Apps

- Web app (Next.js)
- Desktop app (Tauri)

## Planned Shared Packages

- UI
- Core domain models
- Validation schemas
- Data access layer
- Shared utilities

## Project Status

Phase 0 — Repository foundation and architecture planning
