# MiniLedgerPlatform UI Refactor Rules

- This is a Next.js + React + TypeScript + Tauri desktop app.
- Preserve existing business logic.
- Do not change database logic.
- Do not break Tauri desktop mode.
- Keep web mode compatible.
- Reuse existing components.
- Do not add new dependencies unless necessary.
- Improve UI gradually, page by page.
- Before editing, explain the plan.
- After editing, summarize changed files.
